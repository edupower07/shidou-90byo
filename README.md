## 中身
- `index.html` … サイト本体（全30回の目次・各回のまとめ・一枚まとめ・動画）
  - 別シリーズ「90秒でわかる文科省の新資料」（中教審 デジタル学習基盤特別委員会 第11回の配付資料・2026年10月1日）の全8回も同じページに載せています
